## 2. Kết quả chính

BoW + LogReg: F1 test ~0.95, F1 SUB ~0.80, p95 < 5 ms, USD/1k: $0.00.

LLM nhỏ (zero-shot): F1 test ~0.92, F1 SUB ~0.85, p95 ~300-500 ms, USD/1k: ~$0.15.

LLM lớn (zero-shot): F1 test ~0.96, F1 SUB ~0.90, p95 > 1000 ms, USD/1k: ~$2.50.

## 3. Dự đoán và thực tế

Độ trễ LLM: Đoán nhanh hơn thực tế $\rightarrow$ thực tế chậm hơn do API mạng và độ trễ suy luận.
Độ chính xác BoW trên ca lách từ: Đoán BoW bắt được $\rightarrow$ thực tế trượt hoàn toàn do đổi cấu trúc từ.
F1 trên tập SUB: Đoán ổn định $\rightarrow$ thực tế dao động mạnh do cỡ mẫu quá nhỏ (40 case).

## 4. Phân tích 50 case khó

Model tụt nhiều nhất: BoW tụt mạnh nhất ở nhóm né từ khóa và prompt injection.

Case cụ thể: Tin nhắn spam cố tình cách điệu chữ cái (ví dụ: s.p.a.m) hoặc lồng câu lệnh đánh lạc hướng khiến BoW đếm thiếu từ khóa và LLM bị bẻ lái ngữ cảnh.
